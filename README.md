# Кандидатогенерация для поиска услуг Авито

## Подход

Решение объединяет лексический и семантический поиск. BM25 использует заголовок,
параметры и описание объявления с весами 3:2:1. Второй набор индексов строится
после стемминга, чтобы находить совпадения независимо от
словоформ. E5-small покрывает случаи, когда запрос и объявление описывают
одну услугу разными словами: нормализованные векторы сравниваются скалярным
произведением по всему каталогу.

Дополнительно на train-парах обучаются соответствия между словами и биграммами
запросов и термами выбранных объявлений. Positive PMI и минимальная поддержка
отсекают случайные связи; запрос расширяется максимум четырьмя термами с небольшим
весом. География, фильтры и рейтинг учитываются мягкими бонусами, без жёсткого
исключения объявлений. Выдачи объединяются последовательно через взвешенный RRF:
BM25 с E5, затем морфологический поиск, затем поиск с расширением. Глубина
промежуточных списков — 500 кандидатов.

## Запуск

```powershell
# Из корня репозитория.
# В datasets/: train.parquet, benchmark_items.parquet, benchmark_queries.parquet.
uv sync --locked
$env:PYTHONUTF8 = "1"
$env:AVITO_ALLOW_MODEL_DOWNLOAD = "1"
uv run --locked jupyter-execute --timeout=900 solution.ipynb
```
